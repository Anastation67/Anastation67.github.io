## 🔧 Local Development

```bash
# Clone the repository
git clone https://github.com/Anastation67/Anastation67.github.io.git
cd Anastation67.github.io

# Install dependencies (requires Ruby & Bundler)
bundle install

# Run locally
bundle exec jekyll serve

# Open http://localhost:4000
```
